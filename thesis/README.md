# Кваліфікаційна робота (бакалавр) — текст

Тема: **Уніфікована система обробки та класифікації ЕКГ-сигналів різних
форматів з використанням методів машинного навчання**
Студент: Макаренко Вадим Анатолійович, група ТК-41.

Готовий документ: `Кваліфікаційна_робота_Макаренко.docx`.

## Як зібрати документ

```bash
pip install python-docx matplotlib
python3 thesis/make_diagrams.py   # генерує схеми в thesis/figs/
python3 thesis/build_thesis.py    # збирає .docx у thesis/
```

Експериментальні рисунки беруться з `runs/figures/` (їх формує код у
гілці з реалізацією), а схеми архітектури/методів — з `thesis/figs/`
(генеруються `make_diagrams.py`).

## Структура коду генератора

- `build_thesis.py` — налаштування форматування за методичними вимогами
  факультету (A4, Times New Roman 14, інтервал 1.5, береги L25/R10/T20/B20 мм,
  абзац 1.27 см, нумерація сторінок угорі праворуч без номера на титулі),
  титульний аркуш, заголовки, рисунки, таблиці.
- `thesis_content.py` — реферат, перелік скорочень, зміст, вступ.
- `thesis_content2.py` — розділи 1–4, висновки, перелік джерел, додатки.

## Після відкриття у Word

Зміст вставлено як поле `TOC`. Щоб його заповнити сторінками, відкрийте
документ у Word, виділіть весь текст (Ctrl+A) і натисніть **F9** (оновити
поля). Те саме оновить номери сторінок у змісті.

## Відповідність вимогам

- Обсяг основного тексту в межах 40–60 сторінок (бакалавр).
- 28 джерел посилання, оформлених за ДСТУ 8302:2015.
